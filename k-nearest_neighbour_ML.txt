# K-Nearest Neighbors on Diabetes Dataset

import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

from sklearn.metrics import (
    confusion_matrix,
    accuracy_score,
    precision_score,
    recall_score
)

# 1. Load dataset
df = pd.read_csv("diabetes.csv")

# Display first 5 records
print("First 5 rows:")
print(df.head())

# 2. Separate features and target
X = df.drop("Outcome", axis=1)
y = df["Outcome"]

# 3. Split dataset into training and testing data
X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.20,
    random_state=42,
    stratify=y
)

# 4. Feature scaling
# KNN uses distance, so scaling is important
scaler = StandardScaler()

X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# 5. Create KNN model
knn = KNeighborsClassifier(n_neighbors=5)

# 6. Train the model
knn.fit(X_train, y_train)

# 7. Make predictions
y_pred = knn.predict(X_test)

# 8. Calculate confusion matrix
cm = confusion_matrix(y_test, y_pred)

# 9. Calculate performance metrics
accuracy = accuracy_score(y_test, y_pred)
error_rate = 1 - accuracy
precision = precision_score(y_test, y_pred)
recall = recall_score(y_test, y_pred)

# 10. Display results
print("\n----- KNN RESULTS -----")

print("\nConfusion Matrix:")
print(cm)

print("\nAccuracy:", accuracy)
print("Accuracy (%):", accuracy * 100)

print("\nError Rate:", error_rate)
print("Error Rate (%):", error_rate * 100)

print("\nPrecision:", precision)

print("Recall:", recall)





















Q1. What is KNN?

Ans: KNN stands for K-Nearest Neighbors. It is a supervised machine learning algorithm used for classification and regression.

Q2. Why is KNN called a lazy learning algorithm?

Ans: Because it does not build a model during training. It stores the training data and performs calculations during prediction.

Q3. What is the value of K in this practical?

Ans: K = 5, which means the algorithm considers the 5 nearest neighbors.

Q4. Why do we use StandardScaler?

Ans: To bring all features to a similar scale so that large-valued features do not dominate distance calculations.

Q5. Which distance is commonly used in KNN?

Ans: Euclidean distance.

Q6. What is Euclidean distance?

Ans: It is the straight-line distance between two data points.

Q7. What is supervised learning?

Ans: Learning in which the model is trained using labelled data.

Q8. What is classification?

Ans: Classification is used to predict categories or classes, such as diabetic or non-diabetic.

Q9. What is the target variable in the diabetes dataset?

Ans: Outcome. It contains:
- 0 = Non-diabetic
- 1 = Diabetic
Q10. What is the purpose of train_test_split()?

Ans: It divides the dataset into training and testing data.

Q11. What does test_size=0.2 mean?

Ans: 80% data is used for training and 20% for testing.

Q12. What is a confusion matrix?

Ans: It is a table that shows correct and incorrect predictions made by the classification model.

Q13. What is accuracy?

Ans: It is the percentage of total predictions that are correct.

Q14. What is precision?

Ans: It tells us how many predicted positive cases are actually positive.

Q15. What is recall?

Ans: It tells us how many actual positive cases are correctly identified.

Q16. What is the difference between precision and recall?

Ans:
- Precision focuses on correctly predicted positive cases.
- Recall focuses on correctly identified actual positive cases.
Q17. What happens if K = 1?

Ans: The algorithm considers only the nearest neighbor. It may be sensitive to noise.

Q18. What happens if K is too large?

Ans: The model may become underfitted because it considers too many neighbors.

Q19. Why do we use odd values of K?

Ans: To reduce the chances of ties during binary classification.

Q20. What are the disadvantages of KNN?

Ans:
1. Slow for large datasets.
2. Requires feature scaling.
3. Sensitive to irrelevant features.
4. Requires more memory to store training data.
